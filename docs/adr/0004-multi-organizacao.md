# ADR 0004 — Multi-organização

- **Status:** Substituído pelo [ADR 0005](0005-framework-e-hierarquia-generica.md).
- **Data:** 2026-11-09

A ideia de várias organizações no mesmo banco foi descartada: cada uso do código é uma
**instância separada**, com banco, chaves e domínio próprios. Ver ADR 0005.
